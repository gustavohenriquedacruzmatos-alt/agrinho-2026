# 🌾 Agrinho 2026 - Agro Forte, Futuro Sustentável

> Status do Projeto: 🚀 Em desenvolvimento / Concluído

## 📝 Sobre o Projeto
Este site foi desenvolvido como parte do Concurso Agrinho 2026. O objetivo da página é conscientizar a comunidade escolar e a sociedade sobre o tema **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**, destacando como a tecnologia e as boas práticas agrícolas podem caminhar juntas com a preservação do planeta.

O projeto foi construído do zero, aplicando os conceitos de desenvolvimento web aprendidos nas unidades curriculares da **Alura**.

## 🛠️ Tecnologias Utilizadas
De acordo com o cronograma das aulas da Alura, as seguintes tecnologias foram aplicadas:
* **HTML5:** Estruturação semântica da página (tags como `header`, `main`, `section`, `footer`).
* **CSS3:** Estilização, definição de cores, tipografia e alinhamento responsivo utilizando **Flexbox**.
* **Git & GitHub:** Controle de versão e hospedagem do código na nuvem.

---

## 📐 Funcionalidades e Seções do Site
* **Cabeçalho Responsivo:** Menu de navegação rápido para as seções da página.
* **Seção Principal (Home):** Banner de destaque com o tema central do Agrinho 2026.
* **Seção de Conteúdo:** Informações detalhadas sobre práticas sustentáveis no campo.
* **Rodapé:** Identificação dos autores e créditos do projeto.

# 🌾 Agrinho 2026: Inovação e Resiliência no Campo

> **Tema:** Soluções Modernas para o Campo com Identidade Visual Sertaneja e Nordestina.

Este projeto foi desenvolvido como uma proposta de plataforma informativa e prática para o **Concurso Agrinho 2026**. O objetivo do site é apresentar problemas reais que o produtor rural enfrenta na atualidade e apontar soluções tecnológicas viáveis, de baixo custo e ecologicamente sustentáveis, sem perder as raízes e a estética cultural do Nordeste.

---

## 🌵 Características do Projeto

* **Estética Minimalista:** Paleta de cores inspirada na terra, vegetação nativa (Mandacaru) e no artesanato de couro.
* **Design Responsivo:** Adaptado para telas de celulares, tablets e computadores.
* **Foco em Sustentabilidade:** Aborda temas como energia solar, manejo de água por gotejamento e policultura.
* **Acessibilidade:** Inclusão de funcionalidade de alto contraste (Modo Noturno) via JavaScript para facilitar a leitura.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização minimalista, layout em Grid e Flexbox, além de variáveis nativas para controle de temas.
* **JavaScript (Vanilla):** Manipulação do DOM para interatividade e acessibilidade.
